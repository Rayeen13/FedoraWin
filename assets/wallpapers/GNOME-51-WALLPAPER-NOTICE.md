# GNOME 51 Roundhex wallpaper

FedoraWin stores the GNOME 51 light default wallpaper only so Windows CI can produce a real full-desktop FedoraWin screenshot.

- Upstream: GNOME/gnome-backgrounds
- Upstream release: 51.0
- Upstream file: backgrounds/adwaita-l.jxl
- Upstream Git blob: 71e1e91496d82cbe82b9bf9121d4fe23ac81bb21

The capture test temporarily applies a converted copy to the disposable Windows CI runner and restores the runner's previous wallpaper in a finally block. FedoraWin does not force or persist this wallpaper on user systems.
