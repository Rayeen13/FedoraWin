# FedoraWin

FedoraWin is an experimental project to reproduce the current Fedora Workstation / GNOME desktop experience on Windows 11 while preserving native Windows window management, caption buttons, snapping, accessibility, DPI behavior, and recovery.

This repository is the active development workspace. Releases are intentionally withheld until the shell is coherent enough to reasonably call a GNOME clone rather than a cosmetic overlay.
