# FedoraWin documentation site

Static FedoraWin project website and documentation.

- Pure HTML/CSS/JavaScript; no build step.
- Real development screenshots are stored under `docs/assets/screenshots/`.
- GitHub Pages deployment is handled by `.github/workflows/pages.yml`.
- Live site: https://rayeen13.github.io/FedoraWin/
- The site deliberately labels the current build as an alpha preview.

The project is independent and is not affiliated with Fedora Project, Red Hat, GNOME Foundation, or Microsoft.
