What the Gallery proves

The Activities image is generated from the current executable after its native DWM/WinEvent overview code is built. These images prove that the current executable can render the listed shell surfaces on a Windows runner. They do not substitute for physical-device tests of mixed-DPI monitors, touchpads, HDR, unusual GPUs or multi-monitor hot-plug behavior.
