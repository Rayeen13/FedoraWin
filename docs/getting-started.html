Alpha status

FedoraWin 0.4.0-dev is a developer alpha. It is suitable for demonstrations and controlled testing, but it should not yet be treated as a production desktop replacement.

Expect rough edges.

Some Windows surfaces may remain visible, shell behavior is still being refined, and device-specific Quick Settings actions can vary by hardware.

Requirements

  • Windows 11.
  • Windows PowerShell 5.1 with WPF available.
  • A normal desktop session with Explorer and DWM running.
  • Permission to run local PowerShell scripts for the FedoraWin process.

FedoraWin intentionally does not require a replacement shell executable, kernel driver, Windows service, system DLL patch or Explorer replacement.

Run the preflight first

  1. Clone or obtain the current development snapshot.
  2. Open the FedoraWin directory.
  3. Run the provided preflight launcher.
  4. Resolve any reported prerequisite failure before starting the shell.
Preflight.cmd

Run FedoraWin

The current development runtime is PowerShell/WPF based. Start it only after preflight succeeds.

powershell.exe -NoProfile -ExecutionPolicy Bypass -STA -File FedoraWin.ps1

During alpha, the authoritative runnable source is tracked by the development snapshot and CI gate rather than a polished consumer installer.

Optional startup integration

Startup helpers are reversible. Do not enable automatic startup until you have manually tested the shell and recovery path on your machine.

Enable-Startup.cmd
Disable-Startup.cmd

Recovery

If a shell surface behaves incorrectly, exit FedoraWin and restore ordinary Windows behavior rather than forcing the process to remain active.

Restore-Windows.cmd
Design rule:

Recovery is a first-class feature. FedoraWin should never depend on patching Windows components to function.

Report issues

Useful reports include Windows build, display scale, monitor count, affected control, exact steps, screenshots and relevant FedoraWin logs. Never include secrets or unrelated personal data.
