Developer testing

Run the current native shell.

FedoraWin 0.4.0-dev is not an installer release. Test the current Rust/Tauri branch directly and keep Explorer running underneath.

On this pageRequirementsCheckoutRunWindows previewWhat to testRecovery

Requirements

  • Windows 11.
  • Git.
  • Rust toolchain compatible with the repo.
  • Microsoft WebView2 runtime.
  • Normal Explorer/DWM desktop session.

No replacement shell, kernel driver, Windows service or system DLL patch is required.

Checkout the active native branch

git clone https://github.com/Rayeen13/FedoraWin.git
cd FedoraWin
git fetch origin
git checkout dev/gnome-native-20260914
git pull origin dev/gnome-native-20260914

Run FedoraWin

cargo run --manifest-path src-tauri/Cargo.toml

This launches the current Tauri executable, not the retired PowerShell/WPF prototype.

Windows 11 preview executable

The real fedorawin.exe from successful Windows CI #403 → is available under Artifacts → fedorawin-windows11-prebeta (GitHub sign-in may be required). Download the artifact, extract it, then run fedorawin.exe in your normal Explorer desktop session. This is a portable pre-beta test build, not an installer or a replacement for Explorer. Microsoft WebView2 must already be installed.

The binary is an unsigned development executable. Only run a download you obtained directly from this project's verified Actions run, and do not set it as your startup shell.

Useful checks

  • Click Activities and press Alt+F1 from another application.
  • Search for Terminal and Files.
  • Open Calendar and Quick Settings. Confirm rounded popovers blend into the desktop without a rectangular host background.
  • Switch shell light/dark/accent appearance.
  • Test Wi-Fi only if you are comfortable toggling the current adapter.
  • Change display resolution/orientation or attach/detach a monitor and watch shell reflow.
  • Confirm ordinary application resizing, Snap and caption behavior remain Windows-native.
  • With multiple monitors or DPI settings, confirm popovers track the native top bar when displays change.
Not a beta yet.

Do not set this development branch as your permanent startup shell. Bare Super, workspaces and several system controls are still under development.

Recovery

FedoraWin does not replace Explorer. If the development shell misbehaves, open Task Manager with Ctrl+Shift+Esc and end fedorawin.exe. Windows remains underneath.
