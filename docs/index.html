THE SHELL EXPERIENCE

Familiar GNOME patterns.
Native Windows underneath.

The goal is not to paint GNOME over Windows. FedoraWin maps GNOME interaction patterns onto Windows capabilities while preserving native behavior where it matters.

◉

Activities overview

Search, workspace controls, app access and keyboard-driven navigation in one GNOME-style overview.

▦

Application grid

Paged discovery, aliases and practical Windows app matching so searches like Terminal find Windows Terminal.

◫

Native window styling

Real HWND/DWM styling preserves caption buttons, hit-testing, resizing, Snap and ordinary application behavior.

⌁

Quick Settings

Volume, brightness, Wi-Fi, Bluetooth, airplane mode, power mode and more where Windows exposes safe APIs.

◇

GNOME theming

Light, dark and system appearance with libadwaita-inspired accents across shell surfaces.

↔

Virtual workspaces

Overview workspace controls map to Windows virtual desktops without dumping the user into Task View.

ARCHITECTURE

A shell layer, not a Windows replacement.

FedoraWin owns the GNOME-like shell surfaces and delegates window management and system operations back to Windows whenever possible.

WHY ALPHA?

Showcase-ready, not stability-ready.

FedoraWin is coherent enough to show publicly, while still needing runtime hardening, deeper workspace/window presentation, richer Quick Settings behavior and broader device coverage.

10 / 10automated regression tests passing in the latest verified Windows snapshot
The Windows runner also launches and captures the real shell. Physical-device and interactive desktop testing remain release gates.
ROADMAP
