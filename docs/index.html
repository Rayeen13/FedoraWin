THE SHELL EXPERIENCE

Familiar GNOME patterns.
Native Windows underneath.

The goal is not to paint GNOME over Windows. FedoraWin maps GNOME interaction patterns onto Windows capabilities while preserving native behavior where it matters.

◉

Activities overview

Real DWM live-window thumbnails, workspace controls, search, app access and Super/Alt+F1 entry in one GNOME-style overview.

▦

Application grid

Paged discovery, aliases and practical Windows app matching so searches like Terminal find Windows Terminal.

◫

Native window styling

Real HWND/DWM styling preserves caption buttons, hit-testing, resizing, Snap and ordinary application behavior.

⌁

Adaptive Quick Settings

Volume, brightness, radios, power mode, appearance and session actions pack dynamically around the hardware Windows actually exposes.

◇

GNOME-style dock

Favorites and running applications share one model across Activities and an optional persistent desktop dock, with bottom, left and right placement.

↔

Virtual workspaces

A compact GNOME-like workspace strip maps previous, next and new-workspace actions onto Windows virtual desktops.

ARCHITECTURE

A shell layer, not a Windows replacement.

FedoraWin owns the GNOME-like shell surfaces and delegates window management and system operations back to Windows whenever possible.

WHY NOT BETA YET?

The shell is becoming coherent. Runtime breadth still matters.

Activities now presents live Windows through DWM, the dock can live on the desktop, Super can open Activities, and Quick Settings adapts to available hardware. Multi-monitor behavior, motion, broader device coverage and long-session hardening still block a beta label.

EXE CIthe packaged FedoraWin.exe is launched and visually validated on Windows
CI enforces a hidden Windows taskbar and real dark/light transition. Physical-device and interactive desktop testing remain release gates.
